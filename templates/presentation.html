Executive Overview
Project Abstract

With the rapid advancement of quantum computing, conventional password authentication mechanisms are becoming increasingly vulnerable to quantum attacks. Traditional password hashing algorithms alone may not provide sufficient long-term protection against future quantum-enabled adversaries.

Core Innovation

Combines Argon2id memory-hard password hashing with CRYSTALS-Kyber-512 lattice post-quantum cryptography to guarantee zero-knowledge credential verification.

Tech Implementation

Web-based application built using Python Flask, MySQL, HTML5, CSS3, Vanilla JavaScript, and Bootstrap 5.

Motivation & Scope
Problem Statement & Objectives
Problem Statement

• Quantum Cryptanalysis: Quantum computers running Shor's and Grover's algorithms compromise classical public-key cryptography and reduce hash entropy.

• GPU Brute-Forcing: Standard hashes (SHA-256, MD5) allow billions of parallel dictionary attempts per second.

• Lack of PQC Integration: Existing authentication infrastructure lacks post-quantum binding mechanisms.

Key Objectives

1. Design a memory-hard password system using Argon2id.

2. Integrate CRYSTALS-Kyber-512 Post-Quantum Cryptography.

3. Create an unforgeable Quantum Commitment ($C_q$) token.

4. Implement anti-brute-force lockout and audit history logging.

Background Study
Literature Survey & Research Gap
Author / Research Contribution Identified Limitation
Alex Biryukov et al. (Argon2) Introduced Argon2 memory-hard password hashing algorithm. No post-quantum cryptographic key binding mechanism.
NIST PQC Project Standardized quantum-resistant algorithms (CRYSTALS-Kyber). Focuses on key exchange; lacks web password auth integration.
Open Quantum Safe (liboqs) Open-source implementation of PQC primitives. Limited practical application frameworks for user password auth.
Research Gap Addressed

Existing authentication systems rely solely on classical hashes and lack practical frameworks combining memory-hard password hashing with lattice cryptography. QuantumShield resolves this by unifying Argon2id and CRYSTALS-Kyber.

System Design
Proposed Architecture & Pipeline
[User Input] ➔ [Validation] ➔ [Salt (16B)] ➔ [Argon2id Hash] ➔ [Kyber-512 Keygen] ➔ [Quantum Commitment C_q] ➔ [MySQL Persistence]
1. Memory-Hard Hashing

Argon2id ($m=64\text{MB}, t=3, p=4$) allocates 64MB RAM per hash thread to block parallel GPU/ASIC cracking arrays.

2. Quantum Commitment ($C_q$)

$C_q = \text{BLAKE2b-512}(pk \parallel Argon2Hash \parallel Salt)$. Re-verified in constant-time during authentication.
